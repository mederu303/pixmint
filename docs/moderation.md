# pixmint — コピー対策と表示の管理

2026-10-27。Base v4 #4（0x404826e8…5E4f）が、#2「Stormy Day」（@neuromancer）を 1 バイトも違わずコピーミントしたのがきっかけ。

## できること・できないこと

- コントラクト（v3・v4）には、作品を消す・ウォレットを止める機能が無い（誰も作品を消せない、という約束）。**コントラクトを直接呼ばれればミント・売買は防げない。**
- pixmint のサイトでの見せ方と、サイトからの売買は止められる。
- 外のマーケット（OpenSea など）は、そのマーケットに通報する。

## 1. 完全なコピーは自動で見つける

- 作品ページ: 先にミントされた作品と同じデータ（チェーン・版をまたいで探す）なら、「コピーの可能性」と元の作品へのリンクを出す。購入の前にもう一度確認を出す（`findOriginal`・`components/WorkPage.tsx`）。
- MINTED: 読んだ作品の中で、同じデータの 2 つ目からは「コピー」とし、最初は隠す。「コピーも表示（n）」で見られる。
- 1 ピクセルでも変えると完全一致ではなくなるので、それは 2 で手で隠す。

## 2. 手で隠す・止める（`lib/moderation.ts`）

| 一覧 | 書き方 | 効果 |
|---|---|---|
| `HIDDEN_WORKS` | `'<chainId>:<版>:<番号>'` と理由（作品ページに出る） | MINTED・スタンプの一覧に出さない。作品ページに「非表示」と出し、購入・出品のボタンを出さない |
| `BLOCKED_WALLETS` | 小文字のアドレスと理由（記録用） | その作者の作品を全部隠す。サイトからのミント・購入・出品を止める |

書き換えたらデプロイすると反映される。スタンプだけを隠すなら `lib/stampsHidden.ts`。
